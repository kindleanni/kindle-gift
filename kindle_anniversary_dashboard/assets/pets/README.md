# 手绘小鸡替换图

可以直接把你的八张手绘 PNG 放进此目录；程序在下次生成时会自动优先使用它们，并保留内置卡通图作为缺图或图片损坏时的后备。

| 小鸡状态 | 固定文件名 |
| --- | --- |
| 学习中 | `studying.png` |
| 运动中 | `exercising.png` |
| 打游戏中 | `gaming.png` |
| 睡觉中 | `sleeping.png` |
| 做饭中 | `cooking.png` |
| 逛街中 | `shopping.png` |
| 洗澡中 | `bathing.png` |
| 游泳中 | `swimming.png` |

建议每张画布为 **210×170 px** 或同等比例，背景透明 PNG 最佳；白底 PNG 也可以。请用纯黑、深灰和白色，避免细于 2 px 的线条，以确保 Kindle 上清晰。程序会等比缩放并居中，不会裁切。
